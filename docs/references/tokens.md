# Electricity Maps（台灣分區）實測 token

2026-10-23 於 built-in browser 開啟 https://app.electricitymaps.com/zone/TW ，用 `getComputedStyle` 量測；cookie 只保留必要項。截圖：`ref-1440.png`（瀏覽器輸出 800×500，放大回 1440×900）、`ref-390.png`（原生 2× 解析度縮回 390×844）；`-full` 版是資訊面板捲動三段後直向拼接（該站是固定視窗的地圖應用，捲動發生在面板內）。headless 瀏覽器會被該站擋下，未嘗試繞過。Electricity Maps 為 AGPL，只參考版面比例，不取用程式碼或圖示。

## 字體
- 家族：Inter, system-ui, sans-serif；body 14px，顏色 `rgb(230,230,230)`。
- 前幾大文字：區域名 16/500/24px、卡片標題 16/500/24px、主數字（碳強度）16/600、圓環數值 16/600/24px、導覽 14/600/20px。
- 次要：日期與標籤 12/400–600/16px，顏色約 66–85% 亮度灰；軸標 9.6px（30% 不透明）。
- 主焦點靠「色塊」而非字級：碳強度是 76×76px、圓角 16px 的實色方塊（以數值上色）。
