# 設計筆記

這個看板要在十秒內讓人回答三件事：這筆資料新不新、台電今天說供電狀況如何、現在主要靠什麼能源在發電。以下記錄我做過的取捨。資料驗證與過期規則另見 [`DATA_TRUST_CONTRACT.md`](DATA_TRUST_CONTRACT.md)。

## 給誰看

- **一般民眾**：看到新聞說供電吃緊，想用手機確認。需要一眼看到燈號和備轉容量率，不想讀術語。
- **記者與研究者**：需要確切數字、資料時間，能下載。所以每張圖都有表格檢視和 CSV，單位可切換萬瓩／MW。
- **工程同行**：會看資料是否可信、過期時怎麼處理。

台灣的網頁流量約 58% 手機、39% 桌機（StatCounter，2026 年 9 月），所以兩種寬度都要能用：手機首屏就看得到燈號與備轉率，桌機則把狀態面板和趨勢圖並排。

## 參考了什麼

我看了台電今日電力資訊、Electricity Maps、GridStatus、EIA Grid Monitor、英國 NESO Carbon Intensity、東京電力でんき予報、grid.iamkate.com 與 Open Electricity。

- 取自東京電力でんき予報：大數字旁邊常駐門檻說明，所以備轉率旁一直放著 0–25% 的門檻尺。
- 取自 NESO 與 EIA：每個數字都貼著資料時間；每張圖附表格與下載。
- 取自 Open Electricity：圖例就是表格，所以發電結構用「顏色、名稱、數值、占比」同一列。
- 版面比例（左側導覽、卡片面板加大畫布、16px 圓角卡片、Inter 字體、預設深色）參考 Electricity Maps 的台灣分區頁。它的程式碼是 AGPL，所以我只參考版面，沒有使用任何程式碼或圖示。

台電官網的不足也是我想補的：沒有預測參考線、燈號門檻要另開頁面、圖沒有表格替代、要手動重新整理。

## 版面

- 桌機：左側 208px 導覽，中間 458px 狀態面板，右邊是備轉容量率趨勢圖；面板與圖之間 12px。下方依序是今日用電曲線、發電結構、機組、說明。
- 手機：頂部細條、全寬卡片、底部導覽列。
- 首屏順序固定：資料時間、燈號與備轉率、台電五燈號與 0–25% 門檻尺。

## 燈號與資料時間

- 直接採台電官方燈號與用語：綠「供電充裕」、黃「供電吃緊」、橘「供電警戒」、紅「限電警戒」、黑「限電準備」。紅、黑燈以備轉容量（90／50 萬瓩）判定，其餘看備轉容量率。
- 狀態不只靠顏色：每一燈都有不同圖示與文字。
- GitHub 的排程實際約每 3–4 小時才跑一次，所以過期不當成錯誤：資料時間標在主焦點旁，90 分鐘內為即時、6 小時內稍舊（琥珀色）、24 小時內過舊（多一行說明與台電官網連結），超過 24 小時仍顯示最後一筆並標明日期。資料本身的時間在瀏覽器計算，不用部署時間。

## 字體、色彩與間距

- 字體：Inter（自架，只載入拉丁字母子集），中文用系統字體。字級只用一組階梯 12／14／16／18／22／28／36／48／64／96／144px：內文與說明 16px，標籤與控制項 14px，12px 只給圖表座標軸；備轉率是全頁最大的字，96px。
- 色彩：預設深色，可切淺色並記住選擇。深色底 `#0b0f14`、側欄 `#12171e`、面板 `#161d26`、卡片 `#1f2731`；淺色對應 `#f3f4f6`、`#ffffff`。所有文字與背景組合都達 WCAG AA（4.5:1）。
- 間距只用 4／8／12／16／24／32／48／64px；卡片圓角 16px，膠囊形控制項。觸控裝置上所有可點元件至少 44px。
- 動效：只有一個主動播放的動畫，載入時代表答案的那顆燈點亮；其餘動效只回應操作；尊重 `prefers-reduced-motion`。

## 圖示與品牌標記

- 圖示全用 [Lucide](https://lucide.dev)（ISC 授權）：線寬 1.75、圓角端點、無填色，尺寸只用 16／20／24px。同一個概念到處用同一個圖示（例如「供電狀態」是 `gauge`）。
- 品牌標記是翠綠色圓角方形（圓角 22%）加白色 Lucide `zap`（佔 58%、線寬 2）。檔案是 `public/brand/mark.svg`，favicon 與 apple-touch-icon 由它而來。
- 網站上的外部連結只指向台電與政府資料開放平臺。
