# 設計與工程調查摘要（2026-10）

本頁整理改版前的調查，作為 UI/UX 與工程決策的依據。原始調查涵蓋開源專案程式碼、政府與公共機構看板、台電資料端點。

## 參考對象

| 類型 | 對象 | 借鏡 |
| --- | --- | --- |
| 政府／電網營運者 | 台電今日電力資訊、東京電力でんき予報、CAISO Today's Outlook、US EIA Grid Monitor、UK NESO Carbon Intensity、環境部空品監測網 | 門檻圖例常駐在數字旁（でんき予報）；實績實線、預測虛線、「現在」之後淡化（CAISO）；每張圖附表格與下載（NESO）；時間戳緊貼數字（EIA）；狀態色＋圖示＋文字（空品網） |
| 開源看板 | Open Electricity（SvelteKit + Tailwind + shadcn）、Electricity Maps 最後開源前端（React + TS + Vite + Tailwind + Radix）、grid.iamkate.com（PHP 靜態輸出）、apan1121/powerInfoV2、kiang/taipower_data、JacobLinCool/taipower-dashboard | 技術選型與 Electricity Maps 一致；「負載 ÷ 供電能力 ＝ 使用率」等式寫法（iamkate）；嚴格欄數檢查（Electricity Maps 台電 parser）；歷史資料以分支／年份分檔累積（台灣既有專案） |

台電今日電力頁的不足（本站刻意補上）：沒有預測或供電能力參考線、燈號門檻要另開頁面、圖沒有表格替代與下載、要手動重新整理。

## 決策

- **資訊架構**：資料時間列 → 狀態（燈號＋備轉率＋常駐分級）與此刻用電 → 今日用電曲線 → 備轉趨勢（實績＋一週預測）→ 發電結構 → 機組 → 名詞與資料說明 → 來源與下載。
- **燈號**：直接採用台電官方燈號與用語（綠「供電充裕」、黃「供電吃緊」、橘「供電警戒」、紅「限電警戒」、黑「限電準備」）；紅、黑以備轉容量（萬瓩）判定。狀態色只作底色，搭配不同形狀圖示與文字。
- **單位**：預設萬瓩（與台電、新聞一致），可切換 MW；只呈現功率，不與電量（度）混用。
- **今日曲線**：台電沒有全天預測負載曲線，因此以預估尖峰負載水平線＋預估尖峰時段帶＋最大供電能力線呈現，昨日曲線虛線對照。
- **工程**：維持 Vite + React + Tailwind + Radix + ECharts；資料信任邏輯留在框架無關的 `js/`；補上 ESLint（jsx-a11y）、Playwright e2e 與 axe 於 CI。
